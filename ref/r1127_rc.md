## 规矩（必须遵守）
- 用 Chrome 里的 Claude in Chrome 扩展，**新开标签页**打开 https://chatgpt.com （已登录）。不要动制作人已经开着的标签页。
- **草稿保护**：每次打开「新聊天」后，先读输入框。输入框里已经有字的话：把原文完整存到 C:\Users\tlsql\Downloads\sanhua_1127\draft_backup.txt，清空后再用；这一张图出完后把原文原样填回输入框。回报时写明草稿有没有被动过。
- 只碰 C:\Users\tlsql\Downloads\sanhua_1127\ 这个文件夹（没有就建）。下载文件夹里别的文件一律不碰。
- 每张图开一个**新对话**；同一张的修改在同一个对话里接着说。
- 参考图从 https://shinmusong.github.io/sanhua-play/ref/ 下载到 sanhua_1127\ref\ 再上传给 ChatGPT。提示词里写的参考图名 → 实际文件名：去掉开头的 `sanhua_`、前面加 `r1127_`、扩展名改 `.jpg`。例：`sanhua_redraw_ref_chili.png` → `r1127_redraw_ref_chili.jpg`；`sanhua_ref_retsu.png` → `r1127_ref_retsu.jpg`；`sanhua_style_ref_zhangfei.png` → `r1127_style_ref_zhangfei.jpg`。
- 提示词全文：https://shinmusong.github.io/sanhua-play/ref/r1127_prompts_1.md （9 张重出 + イロハ样板 C1～C3）、https://shinmusong.github.io/sanhua-play/ref/r1127_prompts_2.md （阿烈 A1～A6、冰沙 S1）。代码块里的英文原样粘贴，「前半段 + 每张自己的 + 后半段」拼在一起发。
